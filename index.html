ユーザーマニュアル

Clockworker

4系統のクロック／トランスポート出力を、ひとつのテンポとひとつの操作系から扱うための Eurorack クロックジェネレーターです。

はじめに

Clockworker は内部テンポ、外部クロック、USB MIDI、TRS MIDI のいずれかを基準に動作します。選んだクロックを Clock Out A–D、USB MIDI、TRS MIDI へ配信し、START／STOP の状態も同じ基準で扱います。

まずは各部の名称と役割を確認してください。下のパネルは、この章を読み進める位置に合わせて注目する箇所を示します。

各部の名称と基本操作

パネルは上から入出力、中央にメニュー操作、下部に表示とロータリーエンコーダを配置しています。

OLED

128 × 32 の OLED には、現在の BPM、クロックソース、SWING の値、選択中のメニューを表示します。SLEEP を ON にしている場合、操作がないとスクリーンセーバーへ移ります。

ロータリーエンコーダ

HOME 画面では回すと内部テンポを変更します。押すと SWING 画面を開き、もう一度押すと HOME に戻ります。操作中はエンコーダの緑色 LED が点滅します。

START、STOP、TAP

START は内部クロックの再生を開始します。STOP はトランスポートを停止し、出力をアイドル状態へ戻します。TAP は内部テンポをタップ入力するためのボタンです。

SOURCE、PORT、CONFIG

SOURCE ではクロックソースを、PORT では Clock Out A–D の出力内容を、CONFIG では本体、入力、MIDI 出力、更新に関する設定を選びます。

Clock In、Action In、Clock Out A–D

Clock In は外部アナログクロックに同期する入力です。Action In は PLAY、STOP、PLAY/STOP、RESET を実行するトリガー入力です。Clock Out A–D はそれぞれ独立してクロックまたはトランスポート出力に設定できます。

TRS MIDI と USB-C

TRS MIDI と USB MIDI は MIDI Clock とトランスポートを扱います。USB-C は USB MIDI、メンテナンス、ファームウェア更新にも使用します。

再生とテンポ

内部テンポを変更する

SOURCE で INTERNAL を選び、HOME 画面でロータリーエンコーダを回します。BPM の数値が変化し、接続した出力は新しいテンポに従います。

再生を開始・停止する

START で再生を開始し、STOP で停止します。外部クロックを選んでいるときは、Clockworker は選択した入力のクロックとトランスポートを待機します。

クロックソース

SOURCE で選べる入力

INTERNAL は本体で設定した BPM を使います。EXTERNAL は Clock In、USB MIDI は USB-C、TRS MIDI は TRS MIDI 入力からクロックとトランスポートを受け取ります。使用する同期元をひとつ選んでください。

出力ポート

Clock Out A–D を設定する

PORT で対象の出力を選び、分周値または RUN、START、STOP、RESET を設定します。各ポートの極性は個別に切り替えられます。

接続

アナログクロック

外部機器からのクロックは Clock In へ、外部操作用のトリガーは Action In へ接続します。接続前に SOURCE と CONFIG の入力設定を確認してください。

MIDI

USB MIDI または TRS MIDI を使用すると、MIDI Clock とトランスポートを他の機器と同期できます。CONFIG で必要な MIDI 出力を有効にしてください。
