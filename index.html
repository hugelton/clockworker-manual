Introduction

Clockworkerとは

Clockworkerは、4系統のアナログClock Out、アナログClock In、USB MIDI、UART/TRS MIDIを備えたEurorack向けマスタークロック/同期モジュールです。内部テンポで動作するほか、外部アナログクロック、USB MIDI Clock、TRS MIDI Clockに同期できます。

Introduction

特徴

  • 4系統の独立したClock Out A-D
  • 内部96 PPQNクロックエンジン
  • 30.0-250.0 BPMの内部クロック
  • Clock OutごとのPPQN、パルス幅、極性設定
  • RUN/START/STOP/RESETのトランスポート出力
  • アナログClock In、USB MIDI、UART/TRS MIDI同期
  • USB MIDI OUTとTRS MIDI OUTの独立ON/OFF
  • 128x32 OLEDとエンコーダ中心の浅いUI
  • 設定保存とUSBメンテナンス/アップデート機能

Safety

Eurorackへの取り付け

  1. Eurorackケースの電源を必ず切ります。
  2. 電源ケーブルの向き、赤線、-12 V表記を確認します。
  3. モジュールをケースに固定してから電源を入れます。
  4. 初回起動時は、Clock Outを他機器へ接続する前にOLED表示と異常発熱がないことを確認します。

Safety

電源について

電源の接続・取り外しは、必ずケースの電源を切ってから行ってください。

Safety

注意事項

  • Clock Out同士や他機器の出力同士を直結しないでください。
  • Clock Inは必ず保護/レベル変換済みの入力回路を通し、未保護のEurorack信号をGPIOへ直接入れないでください。
  • 同期システム内のマスタークロックは1台だけにしてください。
  • ファームウェア更新や配線変更はトランスポート停止中に行ってください。
  • RUN中に変更した設定はSTOP後に保存されるため、変更直後に電源を切らないでください。

Specifications

パネル仕様

表示はSSD1306 128x32 OLED、操作はロータリーエンコーダとSTART、STOP、ACTION、MENU/SOURCE/PORT/CONFIG系ボタンです。出力はClock Out A-D、入力はClock In、Action In、MIDI IN、USB-Cで、MIDIはUSB MIDIとUART/TRS MIDIに対応します。

Specifications

入出力

  • Clock Out A-D: GPIO28/27/29/26、クロック/トランスポート出力
  • Clock In: GPIO3、外部アナログクロック入力
  • Action In: GPIO2、PLAY/STOP/PLAY-STOP/RESET入力
  • MIDI IN/OUT: UART0 GPIO1 RX / GPIO0 TX、31,250 baud
  • USB-C: USB MIDI、Maintenance CDC、BOOTSEL更新

Specifications

対応クロック

  • 内部BPM: 30.0-250.0 BPM
  • 内部解像度: 96 PPQN
  • Clock In PPQN: 1, 2, 4, 6, 12, 24, 48
  • Clock Out ANALOG: x1, x2, x4
  • Clock Out SYNC: 6, 12, 24, 48 PPQN
  • パルス幅: 1, 2, 5, 10, 15 ms
  • 極性: RISE / FALL
  • MIDI Clock: 24 PPQN

Front Panel

各部名称

Clockworkerは、4系統のクロック／トランスポート出力を持つEurorackクロックジェネレーターです。パネル上では、OLED、ロータリーエンコーダ、START / STOP / TAP、SOURCE / PORT / CONFIG、Clock In / Action In、Clock Out A-D、TRS MIDI、USB-Cを使います。

Display

OLED

128x32 OLEDには、HOMEのBPM、クロックソース、RUN/STOP状態、各メニュー画面が表示されます。SLEEPがONの場合、操作がないとスクリーンセーバーに入ります。

Control

Encoder

ロータリーエンコーダは値の変更、決定、ポート極性の切り替えに使います。HOMEでは回転でBPM、押すとSWING画面へ移動します。

Transport

START / STOP / TAP

STARTは内部クロック開始、または外部ソースの待機に使います。STOPはトランスポートを停止し、出力をアイドルへ戻します。TAPは内部BPMをタップ入力するときに使います。

Menu

SOURCE / PORT / CONFIG

SOURCEではInternal、External Clock、USB MIDI、TRS MIDIを選びます。PORTではClock Out A-Dの出力設定、CONFIGでは本体設定、入力設定、MIDI OUT、Updateを扱います。

Clock I/O

Clock In / Action In / Clock Out A-D

Clock Inは外部アナログクロックへ同期する入力です。Action InはPLAY、STOP、PLAY/STOP、RESETを実行する単発トリガー入力です。Clock Out A-Dは独立してクロック出力またはトランスポート出力に設定できます。

MIDI / USB

TRS MIDI / USB-C

TRS MIDIとUSB MIDIはMIDI Clockとトランスポートを扱います。USB-CはUSB MIDI、メンテナンス、ファームウェア更新にも使います。

Quick Start

電源投入

  1. ケースの電源を切り、Clockworkerを接続します。
  2. Clock Out Aを受け側モジュールのClock Inへ接続します。
  3. ケースの電源を入れます。
  4. OLEDにHOME画面が出て、STOP状態で起動することを確認します。

Quick Start

Internal Clockで動かす

  1. SOURCEを押します。
  2. エンコーダでINTERNALを選び、SOURCEを押して確定します。
  3. HOMEでエンコーダを回してBPMを設定します。
  4. PORTでClock Out Aを任意のPPQNに設定します。
  5. STARTを押します。

Quick Start

外部同期する

  1. 外部クロック源を停止します。
  2. 外部クロック源のClock OutをClockworkerのClock Inへ接続します。
  3. CONFIGでINPUT PPQNとINPUT POLARITYを合わせます。
  4. SOURCEでEXT CLOCKを選択します。
  5. STARTを押し、外部クロック待機状態にします。
  6. 外部クロック源を再生します。

Quick Start

MIDI Clockを送る

  1. SOURCEをINTERNALにします。
  2. CONFIGでUSB MIDI OUTまたはTRS MIDI OUTをONにします。
  3. DAW、シーケンサー、MIDIモニター側でClockworkerを入力先にします。
  4. STARTを押すとFA Start、その後24 PPQNのF8 Clockを送信します。
  5. STOPを押すとFC Stopを送信します。

User Interface

ホーム画面

HOMEにはBPM、ソース、RUN/STOP、A-D出力の概要が表示されます。外部ソース選択中のBPM表示は測定値で、HOMEでBPMを変更しても外部ソースのテンポは変わりません。

User Interface

メニュー構成

  • HOME: BPM、ソース、RUN/STOP、出力概要
  • SOURCE: INT、EXT、USB、MIDI
  • PORT: A-Dごとのタイプ、値、極性、幅
  • CONFIG: SLEEP、MIDI OUT、入力PPQN/極性、Action、Update

User Interface

エンコーダ操作

回すと現在の値や選択肢が変わり、短押しで決定・ON/OFF切替・極性切替を行います。押しながら回すと、HOMEではSwing、PORTでは選択ポートのPulse Widthを変更します。

User Interface

ボタン操作

  • START: トランスポート開始/外部ソース待機
  • STOP: トランスポート停止
  • TAP: INTERNAL時のタップテンポ
  • SOURCE: ソース選択を開く/確定
  • PORT: A、B、C、Dの順にポート画面を移動
  • CONFIG: CONFIGを開く/閉じる

Clock Source

Internal

Clockworker自身のBPM(30.0-250.0)と内部96 PPQNエンジンで動作します。SwingはInternal Clockにのみ適用されます。

Clock Source

Analog Clock In

Clock Inへの外部パルスに同期します。入力PPQNと使用エッジはCONFIGで送信元に合わせ、クロックが約0.5秒途切れると停止します。STOP後は外部エッジだけでは再開せず、再度STARTが必要です。

Clock Source

MIDI DIN

TRS/UART MIDI入力(24 PPQN)をクロックソースにします。StartまたはContinueで待機し、次の安定したF8で開始・同期します。

Clock Source

USB MIDI

USB MIDI入力をクロックソースにし、DAWやPCのMIDI Clockに同期します。USB転送のばらつきはタイムスタンプ補間と軽い外れ値処理で吸収します。

Clock Outputs

Port A-D

各ポートはANALOG(x1/x2/x4)、SYNC(6/12/24/48 PPQN)、TRANSPORT(RUN/START/STOP/RESET)から個別に選べます。デフォルトはA=1 PPQN、B=2 PPQN、C=24 PPQN、D=TRANSPORT RUNです。

Clock Outputs

PPQN

PPQNはPulses Per Quarter Noteの略で、4分音符1拍あたりのパルス数です。120 BPMで24 PPQNの場合、クロック間隔は約20.833 msになります。

Clock Outputs

Pulse Width

パルス幅は1、2、5、10、15 msから選べます。周期に対して幅が長すぎる場合、ファームウェアが実際の周期に収まるよう調整します。

Clock Outputs

Polarity

RISEはアイドルLOW・パルス時HIGHの通常極性、FALLはその反転です。ソース切り替えや停止時は、出力を安全なアイドル状態へ戻します。

MIDI

USB MIDI

USB-C経由でClockworker MIDIとして認識され、入力ソースとしてもMIDI Clock出力先としても使えます。

MIDI

MIDI DIN

ファームウェア上はUART/TRS MIDIとして扱い、GPIO0 TX、GPIO1 RX、31,250 baudを使用します。

MIDI

MIDI Clock

MIDI Clockは24 PPQNです。送信するリアルタイムメッセージはTiming Clock(F8)、Start(FA)、Continue(FB)、Stop(FC)のみで、Note、CC、Program Change、Pitch Bend、SysExは無視されます。

MIDI

Start

マスター時、STARTを押すと有効化されたMIDI OUTへFAを送信します。USB MIDIやMIDI DINがソースの場合は、FA受信で開始待機します。

MIDI

Stop

STOPを押す、またはFCを受信するとトランスポートを停止します。マスター時は有効化されたMIDI OUTへFCを送信します。

MIDI

Continue

FB Continueを受信すると、次のF8 Clockで再開・同期します。マスター時の送信にも対応します。

Sync Compatibility

PPQNとは

PPQNは4分音符1拍に何回クロックを出すかを表します。PPQNが合っていないと、受け側のテンポは整数倍または整数分の1になります。

Sync Compatibility

代表的な同期方式

  • アナログ1 PPQN: 4分音符ごとに1パルス
  • アナログ2 PPQN: 8分音符相当
  • アナログ4 PPQN: 16分音符相当
  • DIN Sync / MIDI Clock: 4分音符あたり24パルス
  • 高解像度モジュラー同期: 48パルス

Sync Compatibility

機器別設定例

Clockworker同士は24 PPQNまたは48 PPQNで送受信PPQNを一致させます。minilogue XDはMIDI ClockまたはSYNC OUT設定に合わせ、TRS/UART MIDI入力での実機同期を確認済みです。機器側の設定はモデルにより異なるため、まずは低いBPMでRISE、5 ms幅から確認してください。

Performance

内部96 PPQNエンジン

内部エンジンは96 PPQNで動作し、各出力のPPQNやMIDI Clockはこのグリッドから生成されます。

Performance

ジッター測定

2026-07-13の実測では、132.0 BPM、Swing 50、5 ms RISEパルスで、1-48 PPQNの平均周期誤差は約-0.004%でした。48 PPQNの10秒測定では標準偏差約10.167 us、ピークtoピーク約123.5 usでした。

Performance

テンポ精度

固定小数点スケジューラにより、以前の整数マイクロ秒丸めによる共通誤差は低減されています。測定上の短期ばらつきはありますが、遅れたtickの後に回復する挙動で、長期的なテンポ誤差として蓄積しないよう設計されています。

Performance

測定環境

Clockworker RP2040 Zero試作機、Release候補ファームウェア、Core1 SIO gate output backend、sigrok capture rate 2 MHzで、Clock Aを中心に測定しました。USB MIDI IN/OUT、TRS MIDI IN/OUT、外部Clock Inは個別に確認しています。Clock B/D物理ジャック、複数DAW/ホスト、長時間外部同期はリリースゲートとして継続確認対象です。

Firmware Update

Bootloader

STOP状態でCONFIGのUPDATEを選び、エンコーダで確定するとRP2040のBOOTSELモードに入り、UF2を書き込めます。

Firmware Update

トラブル時

  • UPDATEはSTOP中のみ受け付け、RUN中の実行は拒否されます。
  • USB MIDIとMaintenance CDCは別インターフェースです。
  • シリアルポートのオープンや1200 baud操作だけではBOOTSELへ入りません。
  • BOOTSELに入らない場合は、RP2040 Zeroの物理BOOTSEL操作でUF2を書き込んでください。

Troubleshooting

同期しない

  • SOURCEが正しいか確認します。
  • STARTを押して外部ソース待機状態にしたか確認します。
  • Clock InのPPQNとRISE/FALLを送信元に合わせます。
  • MIDI同期ではFAまたはFBとF8が送られているか確認します。
  • ケーブルのIN/OUT方向を確認します。

Troubleshooting

テンポが違う

  • PPQN不一致が最も多い原因です。
  • 2倍/半分/4倍のテンポになる場合は、Clock In PPQNまたは相手機器のSync設定を見直します。
  • USB MIDIではホスト側のMIDI Clock送信設定とテンポを確認します。
  • 外部ソース時のBPM表示は測定値であり、内部BPM設定ではありません。

Troubleshooting

MIDIを受信しない

  • SOURCEがUSB MIDIまたはMIDIになっているか確認します。
  • Clockworkerが受け付けるのはF8、FA、FB、FCです。NoteやCCだけを送っても動作しません。
  • TRS/DIN MIDIではケーブル種別、Type A/Type B、IN/OUT方向を確認します。

Troubleshooting

USBを認識しない

  • USB-Cケーブルがデータ対応か確認します。
  • 別のUSBポートまたはハブなし接続を試します。
  • macOS/PC側でClockworker MIDIとClockworker Maintenanceが見えるか確認します。
  • BOOTSEL中は通常のMIDI/CDCデバイスではなくRP2040のUF2ドライブとして見えます。

FAQ

Clock Outから音は出ますか

いいえ。Clock Outは音声ではなく、同期用のパルス/ゲート信号です。

FAQ

MIDIノートで開始できますか

できません。ClockworkerはMIDIリアルタイムメッセージだけをトランスポート/同期に使います。

FAQ

STOP後に設定は保存されますか

保存されます。RUN中はFlashへ書き込まず、STOP後に少し遅延して保存します。

FAQ

外部Clock Inだけで自動開始しますか

STOP後は自動開始しません。STARTまたはAction Inで外部ソースを待機状態にしてから、外部クロックを入力してください。

FAQ

Swingは外部同期にも効きますか

SwingはInternal Clock用です。外部同期中は外部ソースのタイミングを優先します。

FAQ

どの設定から試すべきですか

まずINTERNAL、120 BPM、Clock Out A=1 PPQN、RISE、5 msで確認してください。外部機器へつなぐときは、相手機器のSync設定に合わせてPPQNを変更します。
