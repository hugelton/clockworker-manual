Clockworker

4系統のClock Out、アナログクロック入力、USB MIDI、TRS MIDIを備えたEurorack向けマスタークロック／同期モジュールです。

Clockworkerについて

Clockworkerは内部テンポで動作するほか、外部アナログクロック、USB MIDI Clock、TRS MIDI Clockに同期できます。選択したタイミングをClock Out A〜Dと、有効にしたMIDI出力へ送ります。

  • 個別に設定できる4系統のClock Out
  • 30.0〜250.0 BPMの内部テンポ
  • 出力ごとの分周、パルス幅、極性、トランスポート設定
  • Clock In、Action In、USB MIDI、TRS MIDI

安全上の注意

  • 電源ケーブルを接続・取り外しするときは、必ずEurorackケースの電源を切ってください。
  • 電源を入れる前に、電源ケーブルの赤線と-12 V表記の向きを確認してください。
  • Clock Out同士や、Clock Outと他機器の出力を直結しないでください。
  • Clock InとAction Inには、用途に合ったクロック信号またはトリガー信号だけを接続してください。
  • 接続した同期システムでは、マスタークロックを1台だけにしてください。
  • 設定変更後はSTOPを押し、数秒待ってからケースの電源を切ってください。

クイックスタート

内部クロックで動かす

Clockworker
Clock Out A → 受け側モジュール
Clock In
  1. ケースの電源を切った状態で、Clock Out Aを受け側モジュールのClock Inへ接続します。
  2. ケースの電源を入れ、HOMEがSTOP状態で表示されることを確認します。
  3. SOURCEを押し、エンコーダでINTERNALを選び、もう一度SOURCEを押して確定します。
  4. HOMEでエンコーダを回してBPMを設定します。
  5. STARTを押します。

外部アナログクロックへ同期する

外部機器
Clock Out → Clockworker
Clock In
  1. 外部クロック源を停止し、Clock OutをClockworkerのClock Inへ接続します。
  2. CONFIGでINPUT CLOCK PPQNとINPUT CLOCK POLARITYを送信元に合わせます。
  3. SOURCEでEXTERNALを選択します。
  4. STARTを押して待機状態にしてから、外部クロック源を再生します。

MIDI Clockを送る

Clockworker
USB / TRS MIDI OUT → DAW／シーケンサー
MIDI IN
  1. SOURCEをINTERNALにします。
  2. CONFIGでUSB MIDI OUTまたはTRS MIDI OUTをONにします。
  3. 受け側機器を外部MIDI Clockへ同期する設定にします。
  4. STARTを押すとStartとMIDI Clockを送信し、STOPを押すとStopを送信します。

OLED表示

HOMEにはBPM、選択中のソース、RUN/STOP状態、A〜D出力の概要を表示します。SOURCE、PORT、SWING、CONFIGでは、現在変更している設定を表示します。

ロータリーエンコーダ

回すと値や選択肢を変更し、押すと表示中の設定を確定または切り替えます。HOMEで押すとSWINGを開き、PORTで押すとRISE/FALLを切り替えます。押しながら回すと、HOMEではSwing、PORTではPulse Widthを調整します。

START / STOP / TAP

STARTは内部クロックを開始するか、選択した外部ソースの待機状態にします。STOPはトランスポートを停止し、出力をアイドル状態へ戻します。TAPは一定の間隔で押して内部テンポを設定します。

SOURCE / PORT / CONFIG

SOURCEはクロックソースを選択します。PORTはClock Out A〜Dの設定を開き、押すたびに4つのポートを移動します。CONFIGは本体、入力、MIDI出力、ファームウェア更新の設定を開きます。

クロックとActionの端子

Clock Inは外部アナログクロックを受けます。Action InはPLAY、STOP、PLAY/STOP、RESETを実行するトリガー入力です。Clock Out A〜Dは、それぞれクロック出力またはトランスポート出力に設定できます。

TRS MIDIとUSB-C

TRS MIDIとUSB MIDIは、MIDI Clockとトランスポートメッセージを扱います。USB-Cはファームウェア更新にも使います。

基本操作

HOMEとSWING

  • SOURCEがINTERNALのとき、HOMEでエンコーダを回すとBPMを変更します。
  • エンコーダを押してSWINGを開き、回して50〜75%に設定します。
  • 50%はストレートです。Swingは内部クロックにだけ適用されます。
  • もう一度エンコーダを押すとHOMEへ戻ります。

クロックソース

ソースを選ぶ

SOURCEを押し、エンコーダでソースを選び、もう一度SOURCEを押して確定します。ソースを切り替えるとトランスポートは停止します。

表示動作
INTERNALClockworker自身のBPMで動作
EXTERNALアナログClock Inへ同期
USB MIDIUSB MIDI Clockへ同期
TRS MIDITRS MIDI Clockへ同期

STOP後は、外部クロックだけでは再開しません。もう一度STARTを押して、選択した外部ソースの待機状態にしてください。

クロック出力

Clock Out A〜Dを設定する

PORTを押すとPort Aを開きます。もう一度PORTを押すたびにB、C、Dへ移動します。エンコーダを回してタイプと値を選び、押して極性を切り替え、押しながら回してパルス幅を変更します。

タイプ値用途
ANALOGx1 / x2 / x4基本的なクロック分周
SYNC6 / 12 / 24 / 48 PPQN同期クロック
TRANSPORTRUN / START / STOP / RESETトランスポートゲート／イベントパルス

Pulse Widthは1、2、5、10、15 msから選択できます。RISEはアイドルLOW／パルス時HIGH、FALLはその反転です。

MIDI

MIDI Clockとトランスポート

USB MIDIとTRS MIDIは同じリアルタイムメッセージを使います。受信時は対応するSOURCEを選択し、送信時はCONFIGでUSB MIDI OUTまたはTRS MIDI OUTを有効にします。

ClockworkerはNote、CC、Program Change、Pitch Bend、SysExを使用しません。

設定の保存

内部BPM、Swing、SOURCE、出力設定、MIDI出力設定、入力設定、Action In、SLEEPを保存します。タイミングを保護するため、トランスポート動作中は設定を書き込みません。STOPを押し、数秒待ってからケースの電源を切ってください。

ファームウェア更新

1STOP → 2CONFIG
UPDATE → 3UF2
ドライブ → 4ファームウェアをコピー
  1. トランスポートを停止し、データ通信対応のUSB-Cケーブルでコンピューターへ接続します。
  2. CONFIGでUPDATEを選び、エンコーダで確定します。
  3. UF2ドライブが表示されたら、正しいClockworkerの.uf2ファイルをコピーします。
  4. Clockworkerが再起動するまで待ちます。コピー中はUSBを抜かないでください。

トラブルシューティング

クロックが出ない

  • トランスポートが動作中で、正しいSOURCEが選ばれているか確認します。
  • 使用するポートがTRANSPORTではなく、ANALOGまたはSYNCになっているか確認します。
  • RISE極性と5 msのPulse Widthを試します。

外部同期のテンポが合わない

  • INPUT CLOCK PPQNを送信元のクロックレートに合わせます。
  • 反応しない場合は、INPUT CLOCK POLARITYをもう一方へ切り替えます。
  • ちょうど2倍、半分、4分の1のテンポになる場合は、PPQN不一致を確認します。

USB／TRS MIDIが開始しない

  • 接続に合ったUSB MIDIまたはTRS MIDI SOURCEを選択します。
  • 送信側がTiming Clockに加えてStartまたはContinueを送っているか確認します。
  • MIDI IN/OUTの方向とTRS MIDIケーブルの結線方式を確認します。

USBを認識しない

  • 充電専用ではなく、データ通信対応のUSB-Cケーブルを使います。
  • 別のUSBポート、またはハブを使わない接続を試します。
  • 更新モードでは通常のMIDIデバイスではなく、UF2ドライブとして表示されます。

FAQ

Clock Outから音は出ますか

いいえ。Clock Outは音声ではなく、タイミングパルスまたはトランスポートゲートを出力します。

MIDIノートで開始できますか

できません。ClockworkerはクロックとトランスポートにMIDIリアルタイムメッセージを使います。

Clock Inだけで自動開始しますか

STOP後は自動開始しません。STARTを押して外部ソースを待機状態にしてから、クロックパルスを入力してください。

Swingは外部同期にも効きますか

効きません。Swingは内部クロックにだけ適用され、外部同期では外部ソースのタイミングに従います。
